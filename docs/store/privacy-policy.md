# keyDock 商店版隐私政策

生效日期：2026 年 9 月 21 日

本政策适用于 keyDock 的 Mac App Store 版本。keyDock 是一款在本机运行的应用快捷启动与切换工具。应用无需注册账号，不向开发者上传应用绑定、配置或按键内容。

## 1. 本机处理和保存的信息

为了恢复用户设置，keyDock 在本机沙盒容器内保存所选应用的名称、应用标识、路径、按键绑定、偏好设置，以及手动选择应用时由 macOS 提供的安全作用域书签。书签用于在用户授权范围内恢复对所选应用的访问。

应用会读取本机应用的名称和图标以显示选择列表和键盘面板，并通过 macOS 系统接口启动、激活或请求隐藏指定应用。这些信息不发送给开发者。

## 2. 快捷键与权限

keyDock 只注册用户配置的全局组合键和面板呼出组合键，在自身界面中处理操作所需的按键，不记录日常键盘输入内容。快捷键事件计数和最近操作仅用于本次运行的状态展示。

商店版不要求辅助功能或输入监控权限，不读取其他应用的菜单内容，也不模拟发送按键。

## 3. 数据收集与共享

keyDock 不内置广告、第三方统计、分析 SDK、云同步或账号服务，不将上述本机信息上传至开发者服务器，也不出售或共享这些信息。应用内没有网络服务或追踪功能。

通过 App Store 下载、购买记录、系统诊断等由 Apple 自身提供的服务，遵循 Apple 的相关隐私政策。访问本项目 GitHub 页面时，网页访问由 GitHub 提供服务，遵循 GitHub 的隐私政策；这与 keyDock 应用内的本机处理相区分。

## 4. 保存期限、控制与删除

本机设置会保留以供下次启动使用，直到用户修改或删除。可以在编辑界面清除单个绑定，在设置中暂停快捷键、关闭登录启动，或退出应用。

若要删除全部配置，可从设置定位配置文件，退出 keyDock 后删除该文件。沙盒容器可能在卸载应用后仍由系统保留，因此仅删除应用本身不一定会删除设置。开发者没有这些本机配置的副本，无法远程读取或删除它们。

## 5. 主动反馈

如果用户主动发送邮件或在 GitHub 提交问题，开发者会收到用户提交的邮箱、消息及附件，并将其用于答复、排查问题和提供支持。邮件服务或 GitHub 会按其各自政策处理提交内容。GitHub 公开 issue 对其他访问者可见；请勿在反馈中包含密码、密钥或不必要的个人信息。

如需询问隐私问题，或请求删除主动发送给开发者的反馈资料，请通过下方邮箱联系。请勿发送本机密码或凭据。

## 6. 政策更新

如应用的数据处理方式发生变化，会同步更新本页面并注明新的生效日期。
