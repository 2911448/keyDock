# keyDock 支持

keyDock 商店版是一款免费的 macOS 菜单栏应用启动器，支持 macOS 14 及以上的 Apple Silicon Mac。

## 开始使用

1. 启动后，点击菜单栏中的 keyDock 键盘图标，打开键盘面板。
2. 进入编辑模式，点击字母、数字或标点键，搜索并选择本机应用，然后完成编辑。
3. 默认按 Control + 已绑定的按键调用应用；应用未运行时启动，在后台时切到前台，已经在前台时请求隐藏。
4. 默认按 Option + 空格打开或关闭键盘面板，也可以通过菜单栏打开。
5. 在设置中修改统一前缀和呼出组合，或暂停全局快捷键。登录启动默认关闭，可自行开启。

首次使用没有预设绑定。商店版不提供应用内部功能绑定、双击修饰键呼出或菜单栏图标收纳。

## 常见问题

**快捷键没有反应？** 检查是否仍在编辑模式、设置窗口是否聚焦、是否暂停了快捷键，以及设置中是否报告与系统或其他应用的快捷键冲突。可更换组合键后重试。商店版无需辅助功能授权。

**应用无法隐藏？** keyDock 通过 macOS 公开接口请求隐藏；目标应用未响应时会提示。请反馈目标应用名称、版本、macOS 版本和操作步骤。

**应用移动或卸载后无法打开？** 编辑对应键帽，重新选择该应用，或清除绑定。

**如何清除设置？** 可清除单个绑定；需要删除全部配置时，从设置定位配置文件，退出 keyDock 后删除它。
