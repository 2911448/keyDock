# KeyDock 商店版使用指南

商店版只绑定普通 App，不读取其他 App 菜单、不发送模拟快捷键。

1. 点击菜单栏键盘图标，选择“编辑绑定”。
2. 点击一个字母、数字或标点键，搜索并选择应用；也可手动选择 `.app`。首次使用没有预设绑定。
3. 完成编辑后，在其他应用中按统一前缀 + 对应物理按键。默认前缀为 Control，可以改成 Option 或 Command。
4. 默认用 Option + 空格打开面板，再按字母或点击键帽调用。面板呼出组合可在设置里改成 Control / Command + 空格；Esc 或点击外部关闭。
5. 应用没运行时启动，在后台时激活，在前台时请求隐藏。面板按呼出前的前台 App 判断；目标应用未响应隐藏请求时会提示。

## 快捷键冲突

系统热键注册失败时，设置会列出具体组合及错误码。可换前缀/呼出键，或自行在其他软件中释放该组合，再点“重新检测”。未注册的组合不会被 KeyDock 接管。暂停、编辑、应用选择器和聚焦设置会释放热键，结束后重新注册。

商店版不需要辅助功能或输入监控权限。不支持双击修饰键及 Fn/Shift 单前缀。

## 修改与删除

进入编辑，点击已有键帽可换应用或清除绑定。同一 App 可占多个键。绑定和设置立即保存在本机；文件损坏时不会自动覆盖，可选择保留备份后重置。

应用移动或卸载后如找不到，重新选择即可。手动选择的应用使用系统书签恢复访问。

## 登录启动和隐私

登录启动默认关闭，可在设置打开；系统要求批准时按界面提示操作。退出 KeyDock 或暂停后，全局组合键不再由它处理。

配置位置通过“设置 → 配置文件 → 在 Finder 中显示”查看。要删除全部配置，先退出应用再删除该文件。KeyDock 不上传配置、不保存键盘输入记录。

## 本地预览

预览版名为 KeyDock Store Preview，拥有独立应用容器。它不导入或修改原 KeyDock 1.1.0 的绑定。正式提交前请在预览版验证快捷键、应用切换、多屏、中文输入法及睡眠唤醒。
