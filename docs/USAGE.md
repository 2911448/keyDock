# KeyDock 使用指南

[返回项目首页](../README.md)

## 第一次使用：把 Safari 放到 A 键

1. 将 `KeyDock.app` 放到固定安装位置，例如「应用程序」，双击启动。
2. 点击菜单栏的键盘图标，选择 **打开键盘面板**。
3. 点击面板右上角 **编辑**，再点击 **A** 键帽。
4. 在搜索框输入 `Safari`，点击搜索结果。找不到时可以刷新列表，或使用 **从文件选择…**。
5. 点击面板右上角 **完成**，退出编辑模式。
6. 点击齿轮进入设置，在系统辅助功能权限中允许当前版本的 KeyDock。回到设置点击 **重新检测**，确认 **快捷键监听正常**，然后关闭设置页。
7. 切换到其他应用，按 `Control + A` 显示 Safari；Safari 在前台时再次按 `Control + A` 隐藏。

首次启动没有默认绑定。示例中的 Safari 可以换成任何有效的本机应用。

## 打开与关闭键盘面板

默认单独快速按两次 **Control**：每次都要按下并松开，两次短按在 350 毫秒内完成。不要同时按 A 等其他键，也不要长按 Control。

面板打开后可以直接按已绑定的物理按键，或点击对应键帽调用应用。调用后面板自动收起。关闭面板还可以使用：

- `Esc` 或右上角关闭按钮。
- 点击面板外部或切换窗口使其失去焦点。
- 再次双击呼出键（退出编辑模式、关闭选择器后）。

不便使用双击时，菜单栏 **打开键盘面板** 也可以打开。默认在鼠标所在屏幕中央显示。

## 启动、显示与隐藏的区别

| 调用前的应用状态 | 调用结果 |
| --- | --- |
| 尚未运行 | 启动应用 |
| 在后台或已隐藏 | 激活并显示应用 |
| 已经在前台 | 隐藏应用，保留进程 |

点击键帽、面板内按键和全局组合键使用同一套规则。面板调用依据打开面板前的前台应用判断；隐藏不会退出应用或关闭其文档。

## 添加、替换与删除绑定

进入 **编辑** 后，点击字母、数字或标点键帽，打开应用选择器：

| 需求 | 操作 |
| --- | --- |
| 添加绑定 | 搜索并点击应用 |
| 替换绑定 | 点击已配置的键帽，重新选择应用 |
| 删除绑定 | 点击已配置的键帽 → **清除绑定** |
| 列表没有应用 | 点击刷新按钮，或 **从文件选择…** 手动选择 `.app` |
| 取消当前选择 | **取消** 或关闭应用选择器 |

每个键只能对应一个应用，同一应用可以放在多个键上。修改成功后立即保存，无需另点保存按钮。编辑完成后点击面板右上角 **完成**，恢复快捷键触发。

Esc、功能键、空格和箭头等键帽用于展示布局，首版不能绑定。

## 修改快捷键

在面板齿轮或菜单栏 **设置…** 中修改：

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| 统一前缀键 | 与绑定键一起按下，直接调用应用 | Control |
| 双击呼出键 | 单独连按两次，打开或收起面板 | Control |

两项独立生效，均可选择 Control、Command、Option、Shift 或 Fn／地球键。例如前缀设为 Option、呼出键保留 Control，则 `Option + A` 调用 A，双击 Control 呼出面板。

切换前缀后，新前缀立即应用到所有绑定。组合需要精确匹配：设置 `Control + A` 后，`Control + Shift + A` 不会触发。左右同名修饰键均可识别，Caps Lock 不改变匹配；中文输入法下仍按物理键位触发。

已绑定组合会被 KeyDock 优先处理。选择 Command 时要考虑 `Command + A` 等应用常用组合的冲突。Fn／地球键是否可用取决于键盘和系统设置，设置页可查看事件检测并打开系统键盘设置，KeyDock 不会自动更改系统配置。

## 菜单栏与登录时启动

点击菜单栏的键盘图标：

| 菜单项 | 作用 |
| --- | --- |
| 打开键盘面板 | 直接显示键盘 |
| 编辑绑定… | 打开键盘并进入编辑 |
| 设置… | 打开独立设置窗口 |
| 暂停全局快捷键 | 暂停组合键与双击手势，再点一次恢复 |
| 登录时启动 | 开启或关闭登录后自动运行，默认关闭 |
| 退出 KeyDock | 停止应用及快捷键监听 |

暂停后仍可通过菜单栏打开面板并点击或按面板内的键。编辑状态和应用选择器会暂停启动监听；设置窗口只有获得焦点时暂停，切换到其他应用或关闭设置后恢复。

登录时启动由 macOS 登录项服务管理。如果系统要求额外允许，请按系统提示处理。正常登录启动时在后台运行，可从菜单栏或双击呼出。

## 常见问题

### 权限开关已打开，但仍显示未生效

先在 KeyDock 设置中检查 **快捷键监听正常**，以及按实体按键后 **收到全局按键事件** 是否增长。

1. 点击 **显示当前 App**，确认实际运行位置，避免授权给另一份副本。
2. 在系统 **隐私与安全性 → 辅助功能** 中关闭再开启 KeyDock，再点 **重新检测**。
3. 更新或移动应用后仍失败时，先退出 KeyDock，移除辅助功能列表里的旧条目，重新添加当前位置的 `KeyDock.app` 并允许，再启动。

macOS 要求触控 ID 或密码确认时，在系统窗口中完成。只看到开关开启不足以证明当前版本的监听已生效。

### 双击无反应，或后台快捷键不工作

- 先用菜单栏打开面板，查看监听状态。
- 确认没有暂停，已退出编辑、关闭应用选择器；测试时让其他应用处于前台。
- 确认当前前缀、呼出键和绑定内容；双击使用两次完整短按，不混入其他按键。
- 若只有 Fn 不生效，先使用 Control 验证，并检查地球键检测结果及系统键盘设置。
- 系统保留组合和安全输入模式可能限制监听；仍失败时记录版本、监听状态、按键和目标应用名称，便于排查。

### 显示“无法隐藏”

确认目标确实处于前台，并等待上一次调用完成后再按一次。1.0.4 起会在原生隐藏未生效时尝试通过现有辅助功能权限隐藏，并检查实际状态。若仍失败，检查辅助功能权限及目标应用是否响应；隐藏错误不会退出目标应用。

### 应用移动、卸载或找不到

移动后 KeyDock 会尝试根据应用标识重新定位。如果应用已卸载或重新定位失败，面板会提示错误。进入 **编辑**，点击该键帽重新选择有效的 `.app`，或清除绑定。

### 配置备份、恢复与损坏处理

设置页点击配置文件旁的 **在 Finder 中显示**，可定位：

```text
~/Library/Application Support/KeyDock/settings.json
```

备份时退出 KeyDock 并复制此文件。恢复时先保留当前文件，再用备份替换，重新启动 KeyDock。另一台 Mac 的应用路径可能不同，必要时重新选择应用；系统授权需要在那台 Mac 上单独设置。

配置损坏或版本不兼容时，程序保留原文件并提示。在设置中选择 **保留备份并重置配置** 会先保存损坏文件的副本，再创建空配置；重置后需要重新绑定。

## 更新应用

1. 在菜单栏退出旧版 KeyDock。
2. 用新版替换固定安装位置的 `KeyDock.app`，再打开。
3. 检查监听状态和原有绑定，必要时按上面的步骤恢复授权。

更新 `.app` 不会删除 Application Support 中的绑定。自行构建时继续使用同一签名证书；ad-hoc 临时签名重建后可能需要重新授权。
